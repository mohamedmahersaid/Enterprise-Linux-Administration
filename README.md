## How to use this repository

1. Select a tree based on the operational outcome you need.
2. Read prerequisites and scope before executing commands.
3. Reproduce the lab in an isolated environment.
4. Capture the stated validation evidence.
5. Adapt automation only after review, testing, and rollback planning.
